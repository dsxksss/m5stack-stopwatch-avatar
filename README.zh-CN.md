# KK — M5Stack StopWatch 表情角色

[![构建固件](https://github.com/dsxksss/m5stack-stopwatch-avatar/actions/workflows/build.yml/badge.svg)](https://github.com/dsxksss/m5stack-stopwatch-avatar/actions/workflows/build.yml)
[![许可证：AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](LICENSE)

认识一下 **KK**：一个住在 M5Stack StopWatch 里的小表情角色。

KK 运行在 M5Stack StopWatch 的圆形 AMOLED 屏幕上。它的眼睛、眼皮、眉线、关键帧和过渡均由 C++ 实时绘制，不使用图片序列帧。产品画面保持纯黑背景，并针对 466 × 466 圆屏、局部刷新和直接交互进行了优化。

> 这是一个社区项目，与 M5Stack 官方没有隶属或背书关系。

## 当前固件

当前固件版本为 **0.9.0**。设备动作新增可持久化的低、中、高三级灵敏度，同时作用于倾斜跟随和快速移动惯性。默认“中”完全保留之前的响应；“低”更稳，“高”更快触发。档位只改变输入映射，不改变眼睛的中心安全活动范围。

0.9.0 已完成编译、烧录并在真实 M5Stack StopWatch 启动。串口已依次切换三档，并确认“中”档能在固件重启后继续保留。眼睛菜单中的实际显示效果和三档主观手感仍需用户在真机上验收。

## 主要特点

- 11 种程序化表情：`idle`、`listening`、`thinking`、`happy`、`excited`、`curious`、`confused`、`angry`、`surprised`、`sad`、`sleepy`；
- 通过 GPIO 38 的 CO5300 TE 信号进行硬件垂直同步，以约 60 fps 渲染，并使用动态脏矩形减少 AMOLED 传输开销；
- 支持单击、双击、长按、连续触摸跟随和上下/左右滑动；
- 加速度计与陀螺仪共同驱动倾斜跟随，眼睛先移动、头部稍后跟随，并受中心安全区限制；
- 快速移动设备会产生短暂惯性反馈，但不会切换当前表情；
- 表情由触摸、动作、电量、充电和网络等情境自动驱动，不提供手动表情目录；
- 表情、切换、电量状态、亮度和唤醒均配有原创的柔和 pop、boop、blip 合成音效，安静时段自动静音；
- 同时双击 A+B，在左右眼内竖排显示隐藏生日祝福；长按 A+B 进入硬件诊断；
- 长篇 UTF-8 内容使用独立的全屏六行分页、Unicode 打字机效果，并通过程序化过渡恢复原表情；
- 长按 A 呼出完全由眼睛组成的极简菜单；菜单内单击 A 浏览亮度、音量、动作灵敏度、夜静、网络和固件版本，双击 A 确认，B 返回。普通界面短按 A/B 均不切换表情；向下滑动直接查看电量，设置档位由眼睛睁开幅度表达；
- 45 秒无操作后自动变暗并降低渲染频率，60 秒后清黑并关闭 AMOLED，触摸、按键或明显移动可唤醒；
- 亮度、动作灵敏度、休眠时长和安静时段保存在设备 NVS 中；
- Wi-Fi 连接后通过 NTP 自动同步中国标准时间并写入 RX8130 RTC，RTC 驱动夜间困倦和安静时段；
- 串口语义命令为未来语音识别或外部控制提供稳定入口。

## 完整交互说明

屏幕手势与 A/B 实体按键承担不同功能。普通表情界面短按 A 或 B 会刻意保持无动作，避免误切换表情或误操作已经保存的网络。

### 普通表情与屏幕手势

| 操作 | 结果 |
| --- | --- |
| 单击屏幕 | 短暂显示 `happy` |
| 双击屏幕 | 短暂显示 `surprised` |
| 原地按住屏幕约 650 ms | 短暂显示 `angry` |
| 按住但未越过滑动判定范围 | 眼睛和头部跟随触点 |
| 向右滑动 | 短暂显示 `curious` |
| 向左滑动 | 短暂显示 `confused` |
| 向上滑动 | 短暂显示 `surprised` |
| 向下滑动 | 打开沉浸式电量表情 |
| 缓慢倾斜设备 | 视线在受限的中心安全区内跟随倾斜方向 |
| 快速移动设备 | 眼睛和头部产生短暂惯性，但不改变当前表情 |

`idle`、`listening` 和 `thinking` 是可持续停留的基础状态。点击、长按、滑动、充电和低电量触发的反应都是临时状态，结束后会自动恢复之前的基础表情。

### 实体按键与各模式

| 当前模式 | A 键 | B 键 | A+B |
| --- | --- | --- | --- |
| 普通表情 | 长按约 800 ms 打开眼睛菜单；短按无动作 | 短按无动作 | 同时双击竖排显示生日祝福；同时长按约一秒进入诊断模式 |
| 眼睛根菜单 | 单击切到下一项；双击打开当前项 | 关闭菜单并恢复之前的表情 | — |
| 亮度页 | 单击循环四档亮度 | 返回根菜单 | — |
| 音量页 | 单击循环静音与四档音量 | 返回根菜单 | — |
| 灵敏页 | 单击循环低、中、高三档动作灵敏度 | 返回根菜单 | — |
| 夜静页 | 单击开关定时静音 | 返回根菜单 | — |
| 网络页 | 长按约 1.8 秒配网、重试或换网；短按只刷新状态 | 取消正在运行的配网页面并返回根菜单 | — |
| 版本页 | 只读；单击只产生轻微震动反馈 | 返回根菜单 | — |
| 电量页 | 不修改设置 | 提前关闭 | — |
| 全屏叙事文字 | 单击立即显示完本页或翻到下一页 | 单击显示完/翻页；长按退出 | 同时长按约一秒进入诊断模式 |
| 诊断模式 | 测试震动 | 重绘诊断画面 | 同时长按约一秒回到表情界面 |

根菜单中的单击 A 会在 420 ms 双击判定窗口结束后才切换项目；如果窗口内再次点击，则直接打开当前项目，不会先跳到下一项。眼睛菜单中仍可触摸屏幕让视线跟随，但触摸不会修改设置。

### 六项眼睛菜单

菜单始终保持 KK 的表情形态：项目名称显示在左眼，当前值或位置显示在右眼。

1. **亮度（`1/6`）**：A 在 `60`、`100`、`150`、`220` 四档之间循环；右眼睁开幅度表示当前 `1/4–4/4` 档位。
2. **音量（`2/6`）**：A 在 `0/4–4/4` 之间循环，`0/4` 为静音；右眼睁开幅度表示音量，非静音档位会播放短促试听音效。
3. **灵敏（`3/6`）**：A 在低、中、高三档动作灵敏度之间循环，右眼分别显示“低”“中”“高”。该设置同时调整倾斜和快速移动响应；为避免误唤醒，休眠状态的动作唤醒阈值保持不变。
4. **夜静（`4/6`）**：A 开关并保存 `22:00–07:00` 定时静音。该功能默认关闭且只控制声音，不影响 RTC 驱动的夜间困倦表情。
5. **网络（`5/6`）**：显示未连、连接、已连或失败。按下 A 会先显示“配网”“重试”或“换网”，继续按住约 1.8 秒才启动临时热点 `KK-XXXX`。热点密码是全小写 `kkfriend`，配网期间双眼会拆分显示为 `kkfr | iend`。连接后在自动弹出的页面选择 2.4 GHz Wi-Fi。`XXXX` 只是区分设备的编号，不是密码。候选网络连接成功前不会覆盖原网络；B 可以安全取消配网。
6. **版本（`6/6`）**：显示当前固件版本 `0.9.0`，不会修改任何设置。

### 电量、自动反应与屏幕休眠

- 向下滑动会显示与电量相符的表情：左眼显示充电状态或简短能量描述，右眼显示实测电量百分比，眼睛睁开幅度也表示剩余电量。
- 约 3.4 秒后，电量文字通过眨眼和摇头动画退出，再过约 0.9 秒恢复居中的原基础表情；单击屏幕或按 B 可以提前关闭。
- 接入电源会触发 `excited`，拔掉电源会触发 `curious`；未充电且电量不高于 15% 时，会定期出现 `sleepy` 提醒。
- 无操作 45 秒后，屏幕降至最高 `24/255` 亮度并把渲染降低到 20 fps；60 秒后会先清黑，再彻底关闭 AMOLED。
- 触摸、任一实体按键或确认过的设备动作都可以唤醒屏幕；眼睛菜单、电量页和诊断模式在使用期间保持唤醒。
- 在设定的夜间时段，进入变暗状态时可能显示困倦表情；菜单里的夜静开关只控制该时段的声音，默认关闭。

### 全屏叙事文字

在串口监视器发送 `say <UTF-8 文字>` 即可进入叙事模式。命令保留正文原有大小写，支持中文和显式换行，串口边界最多接收 768 字节。渲染器按 Unicode 字符在圆屏中央安全区自动换行，每页最多六行，超出后自动生成后续页面。

当前表情会先让眼睛和眉毛一起收拢到黑场，随后每个字符以 62 ms 间隔逐渐亮起。内容超过一页时，底部中央以浅灰小字显示 `当前页/总页数`；单页内容不显示。一页打完后会无限停留；打字过程中轻按一次 A 或 B 会立即显示完本页，打完后轻按 A 或 B 才通过从左到右的扫除过渡到下一页，页码随新页同步更新。最后一页继续轻按会循环回第一页，方便重新阅读。叙事模式对 B 独立计时：1.5 秒内松开算轻按，用于补完或翻页；持续按满 1.5 秒才退出并重新睁眼，恢复进入前持续运行的表情。单击屏幕与轻按按键一样用于显示完或翻页。叙事期间屏幕保持唤醒，并暂缓充电和低电量表情，直到原表情恢复。

## 硬件

- [M5Stack StopWatch Dev Kit（C152）](https://docs.m5stack.com/en/core/StopWatch)
- ESP32-S3R8、16 MB Flash、8 MB PSRAM
- 1.75 英寸 466 × 466 圆形 AMOLED 触摸屏
- BMI270 六轴惯性传感器
- CST820B 触摸控制器
- 两个可编程按键和内置震动马达

接口、地址和当前验证边界请参阅[硬件基础资料](docs/HARDWARE_BASELINE.md)。

## 编译

需要准备：

- [PlatformIO Core](https://platformio.org/) 6.1.18
- USB-C 数据线
- M5Stack StopWatch

已经验证的依赖提交均锁定在 [`platformio.ini`](platformio.ini) 中。

```sh
pio run
```

## 烧录与串口监视

通过 USB-C 连接 StopWatch。如果没有自动开始烧录，可以按住复位键约两秒，在绿色 LED 亮起时松开。

```sh
pio run --target upload
pio device monitor --baud 115200
```

串口监视器接受 `happy`、`thinking`、`sleepy` 等表情名称，也支持以下播放测试命令：

```text
once <expression>
loop <expression>
pingpong <expression>
sound
volume 0-160
```

日常伴侣功能还支持以下串口命令：

```text
status
time
time 2026-08-26 20:00:00
brightness 150
motion low
motion medium
motion high
dim 60
screenoff 300
quiet 22 7
wifi
wifi pair
wifi retry
wifi forget
screen on
screen off
say 小谷宝贝，今天也要好好休息。
```

网络校时固定使用中国标准时间 `UTC+8`（`Asia/Shanghai`，无夏令时），联网后自动同步，失败一分钟后重试，成功后每六小时重写 RTC；串口仍可手动校时。`dim` 和 `screenoff` 的单位为秒；亮度、动作灵敏度、超时、夜间静音开关、安静时段和 Wi-Fi 凭据会持久化保存。`KK-XXXX` 中的 `XXXX` 是由本机芯片唯一 ID 派生出的末四位十六进制字符，只用于区分附近的多台 KK。临时热点密码是全小写 `kkfriend`，门户运行时双眼显示 `kkfr | iend`。配网页面仅支持 2.4 GHz 网络，最长开放五分钟，且不会把提交的路由器密码输出到串口。候选网络只有连接成功后才替换旧凭据，失败时会自动恢复原网络。

## 当前限制

- 麦克风和语音/大模型服务尚未接入；Wi-Fi 配网只是传输基础，串口命令仍用于模拟语义语音事件。
- 全屏叙事文字目前从串口或外部控制入口触发，设备端尚未提供正文编辑或语音输入流程。
- 深度睡眠和外部扩展口尚未集成；当前节能策略只关闭 AMOLED，并保持输入采样以便快速唤醒。
- 网络时区目前固定为中国标准时间；如在其他时区使用，仍需增加时区设置入口。
- 尚未完成长期续航测量，默认超时只是安全起点。
- 动作与手势的主观体验可能会随设备握持方式而变化。
